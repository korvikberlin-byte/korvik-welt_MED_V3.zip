# korvik-welt_MED_V3.zip
Statischer 3D-Quantenraster-Simulator

Ein deterministisches, euklidisches Gitter-Modell zur Simulation kosmologischer und 
mikrophysikalischer Prozesse auf einem diskreten 3D-Planck-Raster – völlig ohne Raumkrümmung (ART) und ohne mathematische Singularitäten.
